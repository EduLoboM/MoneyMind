## 📌 Sobre o Projeto

O **MoneyMind** é uma solução disruptiva desenvolvida para revolucionar a saúde financeira dos clientes do **Banco do Brasil**. Consagrado como o projeto **campeão do Hackathon Econsult + BB**, a plataforma reimagina o ecossistema do módulo *Nossas Finanças*, injetando IA profunda, análises preditivas de consumo e interfaces baseadas em neurociência cognitiva aplicada à economia comportamental.

Diferente dos gerenciadores estáticos tradicionais que apenas mostram o passado, o MoneyMind compreende a psicologia de consumo do usuário, antecipa crises de fluxo de caixa e atua de forma proativa antes mesmo que o cliente entre no vermelho.

---

## 💡 Pilares e Funcionalidades Inovadoras

O ecossistema foi projetado para rodar nativamente integrado ao app do Banco do Brasil, trazendo os seguintes módulos core:

* 🧠 **Quiz Comportamental Dinâmico (`QuizCard`):** Mapeia o perfil psicológico-financeiro do usuário (Investidor Consciente, Gastador Impulsivo, Poupador Ansioso) para customizar a linguagem, os alertas e a experiência do app.
* 📊 **Gráficos Preditivos Interativos (`SpendingChart`):** Desenvolvido com **Recharts**, projeta curvas dinâmicas de consumo futuro, permitindo que o usuário visualize o impacto de uma compra de hoje nos próximos 3 meses.
* 🚨 **Crisis Gauge (Medidor de Risco):** Um termômetro visual de estresse financeiro em tempo real que calcula a probabilidade de o cliente precisar recorrer ao cheque especial ou falhar em suas metas de economia.
* 🔔 **Alertas Cognitivos e Nudges (`AlertCard`):** Notificações inteligentes personalizadas com base em gatilhos de comportamento, incentivando o usuário a poupar no exato momento em que costuma realizar gastos por impulso.

## 🛠️ Stack Tecnológica

O front-end do projeto foi projetado com o que há de mais moderno no ecossistema JavaScript para garantir uma experiência ultra fluida e responsiva (UI/UX):

* **React 19.2** (Componentização avançada e hooks de última geração)
* **Vite 8.0** (Build em altíssima velocidade e Hot Module Replacement)
* **React Router Dom 7.17** (Roteamento robusto e SPA de alta performance)
* **Recharts 3.8** (Visualizações e gráficos estatísticos fluidos e interativos)
* **ESLint 10.3** (Padronização rigorosa de código)

## 🚀 Como Inicializar o Ambiente

Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.

### 1. Clonar o repositório e acessar a pasta
```bash
git clone [https://github.com/seu-usuario/moneymind.git](https://github.com/seu-usuario/moneymind.git)
cd moneymind

```

### 2. Instalar as dependências de alta performance

```bash
npm install

```

### 3. Rodar o servidor de desenvolvimento local

```bash
npm run dev

```

O Vite irá disponibilizar a aplicação em `http://localhost:5173`.

### 4. Build para Produção

```bash
npm run build

```

## 🎯 Impacto de Negócio para o Banco do Brasil

A arquitetura do MoneyMind foi pensada sob viabilidade de larga escala para gerar resultados imediatos para o BB:

1. **Redução de Inadimplência:** A IA identifica o risco antes do atraso da primeira fatura, permitindo ações de microcrédito saudável preventivas.
2. **Cross-Selling Inteligente:** Recomendações precisas de fundos de investimento e previdência privada baseadas puramente no perfil comportamental traçado no Quiz.
3. **Engajamento e Retenção:** Gamificação do gerenciador de finanças focado no bem-estar digital do usuário, tornando o app do BB um aliado diário essencial.
